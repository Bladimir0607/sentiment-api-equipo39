🛠️ Cómo configurar el JWT en IntelliJ (OBLIGATORIO)

Run → Edit Configurations

Seleccionar SentimentBackendApplication

Clic en Modify options ▾

Activar:

✅ Environment variables

En Environment variables, pegar:

JWT_SECRET=8jLc0f8Tz/b3CEIIu5u5o7W6KbFc3cWWnmlQMULdSqA=;JWT_EXPIRATION=86400000

En Active profiles, escribir:

local

Luego clic en aplicar y luego en ok
